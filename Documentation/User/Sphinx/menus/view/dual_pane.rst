Dual pane
=========

Choose **View > Dual pane** or press :kbd:`F9` to show two folders side by side.
The current tab appears on the left and the next tab appears on the right.
If only one tab is open, a second tab is opened at the same folder.

Click inside either folder to make it active. The selected tab, address bar,
navigation buttons, status bar and file commands follow the active folder.
Each folder keeps its own navigation history, view settings and selection.
You can copy or cut files in one folder and paste them into the other, or drag
files between the folders using the normal Windows drag-and-drop modifiers.

Selecting another tab replaces the active side only. Selecting the tab already
visible on the other side activates that side without swapping the folders.
The panes share the tab bar. Drag the divider between them to adjust their
widths, or double-click it to restore equal widths. In Details view, each pane
has its own horizontal scrollbar. A scrollbar is disabled when all the columns
already fit.

To choose the folder for the other pane directly, right-click a folder, the
folder view background, or a tab header and choose **Open in Other Pane**.
This enables split view if necessary and keeps the current pane active.
A background tab can be shown directly without creating a duplicate. Opening
the current tab in the other pane creates a second tab at the same folder.
When split view is already enabled, the chosen folder replaces the inactive
pane; the previous folder remains available as a tab.

Press :kbd:`F9` again to return to a single pane. Neither tab is closed.
Closing either visible tab also returns to a single pane. Split view is local
to the current window and is not restored when the application restarts;
the folders remain ordinary tabs and follow the existing tab-saving settings.
